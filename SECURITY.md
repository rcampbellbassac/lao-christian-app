# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.

Use GitHub's private vulnerability reporting for this repository when it is
available, or email **laohollandsda@gmail.com** with:

- a description of the issue and its possible impact;
- the steps needed to reproduce it;
- the affected page, feature, or version; and
- any suggested mitigation you have already identified.

Please avoid including sensitive personal information or ministry data beyond
what is necessary to explain the issue. We will acknowledge the report and
coordinate disclosure after a fix is available.

## Supported version

Security fixes are applied to the current production version on the default
branch. Older deployments and locally modified copies are not maintained.
